# YT Downloader

GUI-приложение на Go + Fyne для скачивания видео с YouTube и X (Twitter).

Поддерживает:
- одиночные видео по ссылке — YouTube (`watch?v=`, `youtu.be`, Shorts, Live)
  и твиты с видео (`x.com/…/status/…`, `twitter.com/…/status/…`)
- каналы и плейлисты YouTube — список с чекбоксами и постраничной загрузкой
- cookies из браузера для видео, закрытых авторизацией или возрастным
  ограничением

Зависимости: [yt-dlp](https://github.com/yt-dlp/yt-dlp), [ffmpeg](https://ffmpeg.org/)

## X (Twitter)

Вставляйте ссылку на конкретный твит: `x.com/username/status/1234567890`.
Лента профиля целиком не выгружается — у yt-dlp нет соответствующего
экстрактора, поддерживаются только отдельные твиты.

Часть роликов на X отдаётся только залогиненным пользователям (приватные
и «чувствительные» твиты). Для них выберите свой браузер в поле
**«Cookies из браузера»** — приложение передаст их в yt-dlp через
`--cookies-from-browser`. Если ссылка не открывается без авторизации,
диалог с ошибкой сам подскажет это сделать.

## Сборка под Windows 11

```
go build -ldflags="-s -w -H windowsgui" -o ytdl.exe .
```

Или через Make:

```
make build
```

Флаг `-H windowsgui` убирает консольное окно при запуске.
